A single sentence of horror for the [One Line, One Chill](https://make.fun/c/u-azazex-one-line-one-chill-6d4d5488) competition on make.fun.

A routine dental visit turns: the dentist finds a second row of teeth growing in behind the narrator's own — teeth that are already chewing, and that already know the narrator's name, spoken in the dentist's own voice. Quiet, specific dread instead of gore: the scare is in what the teeth imply, and in whose voice they use.

## Run

```sh
python3 main.py
```

Writes the one horror line (175 characters, a single sentence) to `/output/entry.txt`, falling back to a local `output/entry.txt` when `/output` is not writable. Pure Python standard library, fully deterministic — repeated runs produce byte-identical output.
